# 梅花易数占卜

基于梅花易数原理的 AstrBot 占卜插件，支持数字起卦与随机起卦，并通过大模型生成风格化卦象解读。

# 提问需符合“四不占”原则:

- **不诚不测**(心念不专则信息失真);
  
- **无事不测**(无实际困惑则无卦可断);
  
- **不义不测**(违背公序良俗之事);
  
- **重卦不测**(同一事反复占卜干扰判断)。
  

## 结果仅作趋势参考:
梅花易数揭示的是当前条件下的发展倾向，并非不可更改的宿命。
若卦象示警，可通过调整行为规避风险这与“趋吉避凶”的易学本意一致。

## 功能一览

### 起卦方式

| 方式 | 示例输入 | 说明 |
|------|---------|------|
| 数字起卦 | `起卦 3 8` | 第一个数定上卦，第二个数定下卦，动爻由两数+时辰算出 |
| 随机起卦 | `占卜` | 无数值时随机生成两数，等同数字起卦逻辑（可在配置中关闭） |
| 带事件起卦 | `占卜 明天面试顺利吗` | 起卦后结合所问之事进行针对性解读 |
| 数字+事件 | `起卦 3 8 明天面试顺利吗` | 用指定数字起卦，并解读所问之事 |

### 触发关键词

`占卜` `起卦` `算卦` `梅花` `梅花易数` `卜卦` `测卦` `问卦` `求卦`

> 必须包含至少一个触发词才会响应，纯数字不会触发。

## 起卦方式详解

### 数字起卦

用户输入两个独立数字时触发。

- **上卦**：数1 % 8（余0取8）
- **下卦**：数2 % 8（余0取8）
- **动爻**：(数1 + 数2 + 时辰地支数) % 6（余0取6）

> 时辰地支数：子=1, 丑=2, 寅=3, 卯=4, 辰=5, 巳=6, 午=7, 未=8, 申=9, 酉=10, 戌=11, 亥=12

### 随机起卦

用户未提供两个数字时，随机生成1-99之间的两个数，按数字起卦规则计算。

### 互卦计算

- **互下卦**：本卦第2、3、4爻（下卦中爻+上爻，上卦初爻）
- **互上卦**：本卦第3、4、5爻（下卦上爻，上卦初爻+中爻）

### 变卦计算

动爻所在卦的该爻阴阳翻转（阳变阴，阴变阳），另一卦不变。

> 断卦口诀：问什么看体卦，问谁看用卦，问过程看互卦，问结果看变卦。

## 体用关系与五行生克

### 体用定义

- **体卦**：不动之卦，代表问事者自身、事情的本质
- **用卦**：动爻所在之卦，代表所问之事、外部影响

> 动爻在下卦（1-3爻）→ 下卦为用，上卦为体  
> 动爻在上卦（4-6爻）→ 上卦为用，下卦为体

### 五行生克关系

**相生链**：金 → 水 → 木 → 火 → 土 → 金

**相克链**：金 → 木 → 土 → 水 → 火 → 金

### 五种体用关系吉凶

| 关系 | 吉凶 | 含义 |
|------|------|------|
| **用生体** | 大吉 | 外部力量助你，事易成，贵人相助 |
| **体用比和** | 吉 | 内外力量均衡，合作顺畅，共谋可成 |
| **体克用** | 小吉 | 你有主动权，事可成但需费力，有阻力 |
| **体生用** | 泄气 | 你消耗自己去成全事，费力不讨好，谨慎 |
| **用克体** | 凶 | 外部力量压制你，事难成，宜守不宜进 |

| 第1爻 | 初爻 | 事之始，事情刚刚萌芽 |
| 第2爻 | 二爻 | 事之渐，事情逐步发展 |

| 第5爻 | 五爻 | 事之盛，事情达到顶峰 |
| 第6爻 | 上爻 | 事之终，事情走向终结 |

## 起卦示例

### 示例一：数字起卦

**输入**：`起卦 3 8`

**计算**：
- 上卦 = 3 % 8 = 3 → 离卦（☲）
- 下卦 = 8 % 8 = 0 → 取8 → 坤卦（☷）
- 假设当前时辰为午时（地支数7）
- 动爻 = (3 + 8 + 7) % 6 = 18 % 6 = 0 → 取6 → 上爻

**结果**：
- 本卦：火地晋（离上坤下）
- 动爻：第6爻（上爻·事之终）
- 体卦：上卦离（火）
- 用卦：下卦坤（土）
- 体用关系：体生用（火生土）→ 泄气

### 示例二：随机起卦

**输入**：`占卜 明天面试顺利吗`

**过程**：
- 未提供数字，随机生成两数（如23、57）
- 上卦 = 23 % 8 = 7 → 艮卦（☶）
- 下卦 = 57 % 8 = 1 → 乾卦（☰）
- 动爻 = (23 + 57 + 时辰) % 6

**结果**：
- 本卦：山天大畜（艮上乾下）
- 互卦：雷泽归妹（震上兑下）
- 变卦：根据动爻翻转后确定

## 输出内容

每次起卦输出包含：

- 起卦方式与当前时间
- 本卦、互卦、变卦的卦名、符号、关键词、卦辞
- 动爻位置与含义
- 体卦/用卦及其五行属性
- 体用关系与吉凶判断
- 五行细析（体与用、互、变的五行关系）
- 万物类象摘要（按角色精要，可通过 `include_xiang_data` 配置关闭）
- LLM 生成的卦象解读（200-{max}字，字数通过 `interpretation_max_words` 配置）

### 解读风格

**四种预设风格**（通过 `default_style` 配置）：

| 风格 | 说明 |
|------|------|
| 白话夹文言（默认） | 白话为主，关键判断用文言点睛，引用卦辞时文言解释时白话 |
| 纯白话 | 全部使用现代汉语口语，通俗易懂 |
| 古风文言文 | 纯正文言文，古雅简练，四六骈句 |
| 俏皮风格 | 口语化、幽默风趣，像朋友聊天，善用比喻和俏皮话 |

**优先级**：`custom_divination_prompt` 填写后，`default_style` 失效，完全使用自定义提示词。

**独立开关**：`allow_emoji`、`allow_action_desc`、`allow_exclamation` 不管是否自定义提示词都生效，分别控制 emoji、动作描述、感叹号的允许与否。

## 配置项

在 AstrBot 管理面板中配置：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `custom_divination_prompt` | string | `""` | 自定义断卦提示词（优先级最高），留空使用 `default_style` |
| `allow_random_divination` | bool | `true` | 是否允许无数字时随机起卦；关闭后必须提供两个数字（如「起卦 3 8」）才能起卦 |
| `default_style` | string | `"白话夹文言"` | 默认解读风格。可选：「白话夹文言」「纯白话」「古风文言文」「俏皮风格」 |
| `include_xiang_data` | bool | `true` | 是否将万物类象发送给 LLM 作为断卦参考；关闭则不加类象 |
| `interpretation_max_words` | int | `500` | 解读最大字数（最小200字），留空或设为0使用默认500字 |
| `allow_emoji` | bool | `false` | 是否允许 LLM 在解读中使用 emoji 表情 |
| `allow_action_desc` | bool | `false` | 是否允许 LLM 添加动作描述（如 `*走*` `*看*`）和角色独白 |
| `allow_exclamation` | bool | `false` | 是否允许 LLM 使用感叹号 |
